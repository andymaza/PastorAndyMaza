PASTORANDYMAZA — PUBLICACIÓN Y EDICIÓN

1. Crea una cuenta en GitHub (github.com).
2. Crea un repositorio nuevo y sube todos los archivos de esta carpeta (no solo index.html).
3. En GitHub: Settings > Pages > Build and deployment > Source: Deploy from a branch > main / (root) > Save.
4. GitHub mostrará la URL pública, generalmente https://USUARIO.github.io/NOMBRE-REPOSITORIO/. Puede tardar unos minutos.
5. Para actualizar los materiales desde cualquier dispositivo: abre contenido.json en GitHub, selecciona Edit, cambia los datos y pulsa Commit changes. GitHub Pages publicará el cambio automáticamente.
6. Para un panel visual de edición sin tocar JSON, se puede conectar después un CMS compatible con GitHub; requiere configurar autenticación.

EJEMPLO PARA resources EN contenido.json:
{
  "title": "La oración de Jabes",
  "type": "Video",
  "category": "Sabiduría",
  "topic": "Oración",
  "description": "Estudio bíblico",
  "url": "https://www.youtube.com/watch?v=ENLACE_REAL"
}

Tipos admitidos: Video, PDF, Keynote. Categorías: Sabiduría, Vida, Fruto.
Temas: Fundamentos de la fe, Oración, Vida en Cristo, Fruto del Espíritu, Propósito y llamado, Personajes Bíblicos, Antiguo Testamento, Discipulado, Principios para la vida.

Nota: GitHub Pages publica un sitio público; no subas archivos privados ni contraseñas. Los archivos .key se pueden subir al repositorio si cumplen sus límites, o enlazar desde almacenamiento público. La edición es privada mediante tu cuenta GitHub, aunque el contenido publicado es público.
